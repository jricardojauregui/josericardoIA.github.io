¿Qué se va a hacer?

Se definirán rangos (bins) para convertir las variables continuas del entorno en estados discretos.

¿Por qué y para qué se hace?

El entorno CartPole maneja valores continuos, pero muchos algoritmos (como Q-learning) requieren estados discretos. Este paso permite transformar el problema en uno manejable mediante tablas.

Resultados

Se definen límites para cada variable del estado:

  • Posición del carrito: [-2.4, 2.4]
  • Velocidad: [-0.5, 0.5]
  • Ángulo del poste: [-0.2, 0.2]
  • Velocidad angular: [-2, 2]

Además, se establecen divisiones (bins):

  • Posición: 1 bin
  • Velocidad: 1 bin
  • Ángulo: 6 bins
  • Velocidad angular: 12 bins

Esto genera un espacio de estados discretos donde:

  • Las variables más importantes (ángulo y velocidad angular) tienen mayor resolución.
  • Las variables menos críticas (posición y velocidad) tienen menor resolución.

Como resultado, el entorno continuo se transforma en un conjunto finito de estados, lo cual permite aplicar métodos de aprendizaje por refuerzo basados en tablas.

First, we'll define the state limits and the number of bins for each observation dimension to discretize the continuous state space. We'll give more bins to angular velocity as suggested.

¿Por qué y para qué se hace?

Inicialmente todos los valores son 0 y no existe conocimiento previo del entorno.

Esto establece la base para que el agente comience a aprender a partir de la interacción con el entorno, actualizando los valores de la tabla conforme avanza el entrenamiento.
