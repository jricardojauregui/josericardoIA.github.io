Paso 6: Identificación de variables significativas entre clusters¶

¿Qué se va a hacer?¶

Se realizarán pruebas estadísticas (t-test) para comparar las variables entre dos clusters específicos (Cluster 1 y Cluster 2).

¿Por qué y para qué se hace?¶

Este paso permite identificar qué variables presentan diferencias significativas entre clusters, lo que ayuda a entender qué características son responsables de la separación observada.

Resultados¶

Se evalúan todas las variables del dataset comparando ambos clusters:

  • Se utiliza un nivel de significancia de 0.05.
  • Para cada variable se calcula un p-value y un estadístico t.

Se obtiene una tabla con las variables significativas, ordenadas por p-value

Las variables con p-value menor a 0.05 indican diferencias estadísticamente significativas entre los clusters.

Esto permite interpretar el clustering desde un punto de vista estadístico, identificando qué variables contribuyen más a la diferenciación entre grupos.

In [ ]:
from scipy.stats import ttest_ind

# Filter df_pca to get indices for Cluster 1 and Cluster 2
indices_cluster1 = df_pca[df_pca['Cluster'] == 1].index
indices_cluster2 = df_pca[df_pca['Cluster'] == 2].index

# Select the original feature data for each cluster
data_cluster1 = df_features.loc[indices_cluster1]
data_cluster2 = df_features.loc[indices_cluster2]

significant_variables = []
alpha = 0.05 # Significance level

print(f"Performing t-tests between Cluster 1 (n={len(data_cluster1)}) and Cluster 2 (n={len(data_cluster2)}) for all {df_features.shape[1]} variables.\n")

# Perform t-test for each variable
for column in df_features.columns:
    # Extract data for the current variable for both clusters
    sample1 = data_cluster1[column]
    sample2 = data_cluster2[column]

    # Perform independent t-test
    stat, p_value = ttest_ind(sample1, sample2, equal_var=False) # Welch's t-test assuming unequal variances

    # Check for significance
    if p_value < alpha:
        significant_variables.append({'Variable': column, 'p-value': p_value, 't-statistic': stat})


# Convert results to DataFrame for better display
significant_df = pd.DataFrame(significant_variables).sort_values(by='p-value').reset_index(drop=True)

if not significant_df.empty:
    print(f"Found {len(significant_df)} significant variables between Cluster 1 and Cluster 2 (p < {alpha}):")
    display(significant_df)
else:
    print(f"No significant variables found between Cluster 1 and Cluster 2 at p < {alpha}.")

Paso 10: Corrección por pruebas múltiples¶

¿Qué se va a hacer?¶

Se ajustarán los p-values obtenidos anteriormente utilizando métodos de corrección por pruebas múltiples: Bonferroni y Holm.

¿Por qué y para qué se hace?¶

Cuando se realizan muchas pruebas estadísticas, aumenta la probabilidad de encontrar resultados significativos por azar. Estas correcciones reducen ese riesgo, haciendo el análisis más confiable.

Resultados¶

Se obtiene un DataFrame con los p-values originales y los ajustados. Además, se reporta el número de variables que siguen siendo significativas después de cada corrección:

  • Bonferroni: (número de variables significativas)
  • Holm: (número de variables significativas)

Se observa que el número de variables significativas disminuye tras la corrección, especialmente con Bonferroni, que es más conservador. Esto indica que algunas variables inicialmente significativas podrían haber sido falsos positivos.

In [ ]:
from statsmodels.stats.multitest import multipletests

# Extraer los p-values del DataFrame de variables significativas
p_values = significant_df['p-value'].values

reject_bonferroni, p_values_bonferroni, alphac_bonferroni, alphacSidak_bonferroni = multipletests(p_values, alpha=alpha, method='bonferroni')
significant_df['p-value_Bonferroni'] = p_values_bonferroni

Paso 11: Discretización del espacio de estados¶

¿Qué se va a hacer?¶

Se definirán rangos (bins) para convertir las variables continuas del entorno en estados discretos.

¿Por qué y para qué se hace?¶

El entorno CartPole maneja valores continuos, pero muchos algoritmos (como Q-learning) requieren estados discretos. Este paso permite transformar el problema en uno manejable mediante tablas.

Resultados¶

Se definen límites para cada variable del estado:

  • Posición del carrito: [-2.4, 2.4]
  • Velocidad: [-0.5, 0.5]
  • Ángulo del poste: [-0.2, 0.2]
  • Velocidad angular: [-2, 2]

Además, se establecen divisiones (bins):

  • Posición: 1 bin
  • Velocidad: 1 bin
  • Ángulo: 6 bins
  • Velocidad angular: 12 bins

Esto genera un espacio de estados discretos donde:

  • Las variables más importantes (ángulo y velocidad angular) tienen mayor resolución.
  • Las variables menos críticas (posición y velocidad) tienen menor resolución.

Como resultado, el entorno continuo se transforma en un conjunto finito de estados, lo cual permite aplicar métodos de aprendizaje por refuerzo basados en tablas.

First, we'll define the state limits and the number of bins for each observation dimension to discretize the continuous state space. We'll give more bins to angular velocity as suggested.

Paso 12: Función de discretización del estado¶

¿Qué se va a hacer?¶

Se implementará una función que convierte una observación continua en un estado discreto utilizando los bins definidos previamente.

¿Por qué y para qué se hace?¶

Este paso es necesario para mapear los valores continuos del entorno a índices discretos, lo que permite utilizar estructuras como tablas Q en algoritmos de aprendizaje por refuerzo.

Resultados¶

La función recibe:

  • Una observación del entorno (valores continuos).
  • Los bins definidos para cada variable.
  • Las dimensiones del espacio de estados.

Y devuelve:

  • Una tupla de valores enteros que representan el estado discretizado.

Características del resultado:

  • Cada valor corresponde al índice del bin en el que cae cada variable.
  • Los índices se ajustan para evitar valores fuera de rango.
  • El estado final es una representación discreta del entorno.
In [ ]:
def discretize_state(observation, bins, state_dims):
    state = []
    for i, feature_bins in enumerate(bins):
        # Use np.digitize to find the bin index for each observation feature
        # np.digitize returns indices for bins, from 1 to N_bins.
        # For values < feature_bins[0], it returns 0. For values >= feature_bins[-1], it returns len(feature_bins).
        digitized_index = np.digitize(observation[i], feature_bins) - 1

        # Clamp the index to be within the valid range [0, state_dims[i] - 1]
        clamped_index = max(0, min(digitized_index, state_dims[i] - 1))
        state.append(clamped_index)
    return tuple(state)

Paso 13: Inicialización de la Q-table¶

¿Qué se va a hacer?¶

Se creará una tabla Q (Q-table) inicializada en ceros, considerando los estados discretizados y el número de acciones posibles.

¿Por qué y para qué se hace?¶

La Q-table es la estructura principal en Q-learning, donde se almacenan los valores esperados de recompensa para cada combinación de estado y acción. Inicializarla es el primer paso para que el agente pueda aprender.

Resultados¶

Se obtiene una Q-table con dimensiones:

  • Dimensiones de estado: determinadas por los bins definidos previamente.
  • Dimensión de acción: igual al número de acciones posibles (2 en CartPole).

La forma de la Q-table es:

  • (dim_estado_1, dim_estado_2, dim_estado_3, dim_estado_4, num_acciones)

Inicialmente todos los valores son 0 y no existe conocimiento previo del entorno.

Esto establece la base para que el agente comience a aprender a partir de la interacción con el entorno, actualizando los valores de la tabla conforme avanza el entrenamiento.

Paso 15: Entrenamiento con Q-Learning¶

¿Qué se va a hacer?¶

Se entrenará un agente utilizando el algoritmo Q-Learning, permitiéndole interactuar con el entorno y actualizar la Q-table en cada paso.

¿Por qué y para qué se hace?¶

Este paso permite que el agente aprenda una política óptima para maximizar la recompensa, es decir, mantener el poste equilibrado el mayor tiempo posible.

Resultados¶

Durante el entrenamiento:

  • Se ejecutan múltiples episodios (5000).
  • En cada paso, el agente decide entre explorar (acción aleatoria) o explotar (mejor acción conocida).
  • Se actualiza la Q-table usando la ecuación de Bellman.
  • Se reduce progresivamente el valor de epsilon (menos exploración, más explotación).

  • Una lista de recompensas por episodio.
  • Una Q-table actualizada con conocimiento del entorno.

Observaciones:

  • Al inicio, las recompensas suelen ser bajas debido a la exploración.
  • Con el tiempo, las recompensas aumentan conforme el agente aprende.

Esto indica que el agente está aprendiendo una estrategia para mejorar su desempeño en el entorno.

In [ ]:
import random

env = gym.make('CartPole-v1') # Create a new environment for training

episode_rewards_q_learning = []

print("Starting Q-Learning training...")

for episode in range(num_episodes):
    observation, info = env.reset()
    current_state = discretize_state(observation, bins, state_dims) # Pass state_dims
    episode_reward = 0

    for step in range(max_steps_per_episode):
        # Epsilon-greedy policy: choose action
        if random.uniform(0, 1) < epsilon:
            action = env.action_space.sample() # Explore: choose random action
        else:
            action = np.argmax(q_table[current_state]) # Exploit: choose best action from Q-table

        # Take action and observe new state and reward
        next_observation, reward, terminated, truncated, info = env.step(action)
        next_state = discretize_state(next_observation, bins, state_dims) # Pass state_dims

        # Update Q-table using the Bellman equation
        old_value = q_table[current_state + (action,)]
        next_max = np.max(q_table[next_state])

        new_value = old_value + learning_rate * (reward + discount_factor * next_max - old_value)
        q_table[current_state + (action,)] = new_value

        current_state = next_state
        episode_reward += reward

        if terminated or truncated:
            break

    episode_rewards_q_learning.append(episode_reward)

    # Decay epsilon
    epsilon = max(epsilon_min, epsilon * epsilon_decay)

    if (episode + 1) % 100 == 0:
        print(f"Episode {episode + 1}/{num_episodes}, Epsilon: {epsilon:.4f}, Reward: {episode_reward}")

env.close()
print("Q-Learning training finished.")

import gymnasium as gym
import numpy as np

# Create a new environment for evaluation
env_eval = gym.make('CartPole-v1')

# We will run for a few episodes to get a sense of performance
num_eval_episodes = 100
max_eval_steps = 500 # Max steps per episode for CartPole-v1

eval_rewards = []

print(f"Evaluating trained Q-learning agent for {num_eval_episodes} episodes...")

for episode in range(num_eval_episodes):
    observation, info = env_eval.reset()
    current_state = discretize_state(observation, bins, state_dims)
    episode_reward = 0

    for step in range(max_eval_steps):
        # Always exploit: choose the action with the highest Q-value
        action = np.argmax(q_table[current_state])

        next_observation, reward, terminated, truncated, info = env_eval.step(action)
        next_state = discretize_state(next_observation, bins, state_dims)

        current_state = next_state
        episode_reward += reward

        if terminated or truncated:
            break

    eval_rewards.append(episode_reward)

print(f"Evaluation finished. Average reward: {np.mean(eval_rewards):.2f}")
print(f"Max reward: {np.max(eval_rewards)}")
env_eval.close()
